# Archived designs

Design features that are superseded, retired or parked live here, one folder per feature.

- A moved feature keeps its folder name: `docs/design/_archived/<feature>/`.
- Nothing in `_archived/` is authoritative. Do not implement from these docs or treat them as describing current behavior; each one carries `status: Deprecated` and a pointer to its replacement or the reason it was archived.

How to archive a design is in [design conventions](../CONVENTIONS.md#archiving-a-design).
