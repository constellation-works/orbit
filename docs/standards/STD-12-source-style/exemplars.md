# Exemplars — STD-12 Source style

Worked examples of the rules in [STD-12](STD-12.md). Unlike the other standards, the exemplars for this one live in `rust-cli-template` (`codebases/rust-cli-template`), not in Orbit: the template carries the gates first, and a project made from it starts compliant.

None is in place at v1. The template's store is being reshaped to R1 (`driver/sqlite/schema/note.rs`, `repository/note.rs`, `app/`, `contract/`) and its check script is not yet built. Each pointer is added here, as an editorial change, when the template change that carries it lands.

- R1 — pending: `rust-cli-template` `crates/tmpl-cli-store/src/driver/sqlite/schema/`
- R8 — pending: an exemplar of a named guarantee in the template store
- R12, R13, R16, R19 — pending: `rust-cli-template` `scripts/check-source-style.sh`
