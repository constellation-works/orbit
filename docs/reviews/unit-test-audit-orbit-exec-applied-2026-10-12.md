# orbit-exec unit-test audit application

The pinned audit at `dd268d0d5a1640b709bcac0d3759b04879f77a14` is historical evidence. This
application checks its 41 owned non-admitted identities against delivery base
`1bac2703c56dc0defd8d10b3733ff814f78e0113`: 23 relocate to existing
crate-root integration binaries, two retire into existing controls, six
retain specific private security seams, and ten were already moved out of
orbit-exec by the shared supervisor extraction.

Public helper APIs suffice for the compiler, build-log, login-shell and grant
fixtures. Native sandbox cases stay in `tests/sandbox/main.rs`, with their
original macOS platform guards. The public phase environment/cwd case runs on
the two platforms that support build sandboxes (Linux and macOS).
Environment-sensitive compiler fixtures run one test
in an isolated child, then call the exported compiler against the synthetic
environment; they never read operator credentials. The PTY parent and ignored
child move together, and the parent checks the child's exact test name.

The symlink measurement case uses the public phase with a zero directory cap:
its host-side walk must not count the unchanged outside-file fixture. The
retired missing-path assertion joins the designated fail-closed unreadable
measurement fixture (audit ordinal 680).

The original 18 admitted identities remain intact where their code survives.
Before this application, `4be446d38` moved four admitted supervisor/tee fixtures
and the ten owned wait identities to orbit-common. `93d3fcb1f` removed the
profile cache and its three admitted cache-lifetime fixtures in favor of private
per-spawn profiles and the existing macOS profile-integrity integration case.
Neither change is undone here. The two pre-sandbox exit/capture fixtures added
since the audit also remain intact.

The baseline is regenerated by `scripts/unit-test-inventory.py --write-baseline
scripts/unit-test-baseline.json`, keeping every other crate's existing section.
Empty macOS compile/provider/spawn unit modules, top-level path/login unit
declarations, and their unused support are removed. The compiler's former
test-only environment-input visibility becomes private. Production behavior
and dependencies stay the same.

## Private seam corrections

- `a_timed_out_phase_takes_its_process_group_with_it`: Keep under criterion 3 at build_sandbox::supervise::run. The fixture records a background PID and uses host kill(pid, 0) to certify reaping. The public Linux build path unshares the PID namespace, so that PID cannot identify the host process; substituting it would weaken the assertion. The same pre-sandbox fixture remains runnable on both Unix hosts.

- `the_fetch_ruleset_refuses_tcp_to_any_port_but_443`: Keep under criterion 3 at linux_landlock::restrict_child_tcp_connect_to_port. The fixture installs only the fetch TCP ruleset on the same bash program as its unconfined control. The public build path adds filesystem confinement and Bubblewrap namespaces, which can prevent connection for a different reason; the exported plugin network boundary only offers deny-all TCP. Neither substitutes the same ruleset-only guarantee.

- `a_second_path_to_a_credential_dir_refuses_the_plan`: Keep under criterion 3 at append_credential_masks with explicit denies and no_mounts. The fixture injects a bind from a descendant of .ssh to /mnt/elsewhere, which the exported compiler cannot request as an arbitrary source/destination pair. It proves refusal before an incomplete credential mask can start.

- `host_alias_reports_a_second_mount_that_holds_the_target`: Keep under criteria 2 and 3 at host_alias with injected MountEntry records. Synthetic same-device mount roots and a real symlink force matching device/inode identities for a second mount containing the target. The public compiler reads /proc/self/mountinfo and cannot inject this table without privileged mounts.

- `host_alias_reports_a_second_mount_of_part_of_the_target`: Keep under criteria 2 and 3 at host_alias with injected MountEntry records. Synthetic same-device mount roots and a real symlink force an alias exposing only a descendant of the masked tree. The public compiler reads /proc/self/mountinfo; reproducing the table would require privileged mounts.

- `a_user_writable_or_symlinked_bundled_copy_is_refused_before_spawn`: Keep under criterion 3 at trusted_wrapper_at with an injected bundled location. It exercises actual ownership and symlink metadata against a disposable binary copy. Public wrapper selection only verifies fixed /usr/bin/bwrap and /usr/local/libexec/orbit/bwrap; replacing those requires privileged host writes and is outside this task.

Linux gates exercise the exported helper and Linux cases. The moved native
macOS cases compile only on macOS and require that CI leg's
`ORBIT_REQUIRE_SANDBOX_EXEC=1`; Linux results do not certify their kernel
behavior. The source relocation preserves those guards and child entry points.
Native Seatbelt guards run in the parent before isolated re-execution, so an
apply refusal remains visible to the validation gate.

The initial affected run exposed two fixture-placement failures: a synthetic
HOME beneath the worker worktree was reachable through its stable mount alias,
so the public compiler correctly refused an incomplete credential mask. The
compiler-only credential fixtures now retain their original temporary-home
layout, outside the worktree alias, and set HOME/CARGO_HOME only in their
isolated process. The original credential assertions remain unchanged.
