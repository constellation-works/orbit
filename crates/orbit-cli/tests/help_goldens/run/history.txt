Show recent job runs filtered by job, task, state or time

Usage: orbit run history [OPTIONS]

Options:
  -j, --job <JOB_ID>
          Filter to one job ID

      --task <TASK_ID>
          Filter to runs whose input names this task

      --state <STATE>
          Filter to any of these comma-separated run states

      --since <SINCE>
          Only runs created at or after this RFC 3339 time or relative duration (24h, 7d)

      --limit <LIMIT>
          Maximum number of runs to show
          
          [default: 50]

      --no-reconcile
          Report stored run records as-is, skipping stale-run reconciliation

      --incidents
          One row per incident, folding runs that failed only because a child did

      --failures
          One row per task and root cause, with that run's step, crew and cause

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header

ROLE says how a run was submitted: top-level directly, child by a parent run.
JSON shapes, ROLE markers and how --incidents and --failures fold runs: installed orbit-orchestrate skill `references/run-debugging.md`.
Examples:
  orbit run history
  orbit run history -j task_local_pipeline --limit 20
  orbit run history --state failed,held --since 24h
  orbit run history --state failed --incidents
  orbit run history --state failed --failures
  orbit run history --json
  orbit run history --limit 200 --no-reconcile --json
