Cancel a pending or running job run

Usage: orbit run cancel [OPTIONS] <RUN_ID>

Arguments:
  <RUN_ID>
          Job run ID to cancel

Options:
      --confirm
          Confirm process termination and irreversible run terminalization

      --reason <REASON>
          Optional reason recorded with the cancellation audit event

      --force
          Do not wait for a drain's in-flight leaves: stop them too, returning a pull drain's claims to the owner's backlog

      --block
          Keep a cancelled task leaf blocked instead of returning it to the backlog

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header

Stops a pending or running run, releases its task reservations and marks it `cancelled`;
a finished run reports `already_terminal`. A cancelled task leaf returns its task to the
backlog unless `--block`. A pull drain cancels gracefully, waiting for launched leaves
unless `--force`; `--force` also stops a local drain's child runs. Exits 1 if a stop
cannot be confirmed.

Examples:
  orbit run cancel jrun-20260706-0120-2 --confirm
  orbit run cancel jrun-20260706-0120-2 --confirm --block --reason "needs review"
  orbit run cancel jrun-20260706-0120-2 --confirm --force --reason "host maintenance"
  orbit run cancel jrun-20260706-0120-2 --confirm --json
