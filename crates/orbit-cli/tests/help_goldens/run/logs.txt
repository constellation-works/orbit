Print raw stdout/stderr captured for a job run

Usage: orbit run logs [OPTIONS] [RUN_ID]

Arguments:
  [RUN_ID]
          Run ID to inspect. Defaults to the most recently scheduled run globally

Options:
  -s, --step <STEP_ID>
          Show raw logs for a single activity step.id from the v2 job YAML

  -f, --follow
          Stream output until the run is terminal. JSON output is JSONL

      --no-reconcile
          Report stored run records as-is: skip stale-run reconciliation, which finalizes an orphaned pending or running run as interrupted, releases its task reservations, and settles with their owner the pull claims an ended drain or leaf left

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header

JSON shape and --follow records: installed orbit-orchestrate skill `references/run-debugging.md`.

Examples:
  orbit run logs
  orbit run logs jrun-20260426-0631 --follow
  orbit run logs jrun-20260426-0631 -s implement_one --json
