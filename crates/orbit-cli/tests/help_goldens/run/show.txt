Show structured state and step summary for a job run

Usage: orbit run show [OPTIONS] [RUN_ID]

Arguments:
  [RUN_ID]
          Run ID to inspect. Defaults to the most recently scheduled run globally

Options:
  -s, --step <STEP_ID>
          Show a single activity step.id from the v2 job YAML

      --no-reconcile
          Report stored run records as-is: skip stale-run reconciliation, which finalizes an orphaned pending or running run as interrupted, releases its task reservations, and settles with their owner the pull claims an ended drain or leaf left

      --verbose
          Also list the catalog layer of every job and activity reference; by default only references that did not resolve to a shipped definition

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header

JSON shape, step index base and duration units: installed orbit-orchestrate skill `references/run-debugging.md`.

Examples:
  orbit run show
  orbit run show jrun-20260426-0631
  orbit run show jrun-20260426-0631 -s implement_one --json
