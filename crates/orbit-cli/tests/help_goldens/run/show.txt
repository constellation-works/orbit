Show structured state and step summary for a job run

Usage: orbit run show [OPTIONS] [RUN_ID]

Arguments:
  [RUN_ID]
          Run ID to inspect. Defaults to the most recently scheduled run globally

Options:
      --root <ROOT>
          Orbit data directory to use (overrides every other source)

  -s, --step <STEP_ID>
          Show a single activity step.id from the v2 job YAML; legacy target ID and index still work

      --no-reconcile
          Report stored run records as-is: skip stale-run reconciliation, which finalizes an orphaned pending or running run as interrupted, releases its task reservations, and settles with their owner the pull claims an ended drain or leaf left

      --workspace <SELECTOR>
          Active workspace to use: registered name, `ws_*` ID or checkout path

      --verbose
          Also list the catalog layer of every job and activity reference; by default only references that did not resolve to a shipped definition

      --format <MODE>
          Output format (default: auto — a table on a terminal, plain text when piped)

          Possible values:
          - auto:   Decide from the sink: a table on a terminal, plain text otherwise
          - table:  Aligned columns with a header
          - plain:  Untruncated text with tab-separated fields; a header row only with --header
          - json:   A single JSON document
          - ndjson: One complete JSON document per line

      --json
          Output as JSON (shorthand for --format json; always pretty-printed)

      --header
          Start plain output with a tab-separated header row (table output always has one)

  -h, --help
          Print help (see a summary with '-h')

JSON: {"run":<job-run>,"pull_claim":…,"crew_window":…,"catalog_layers":[…],"pipeline_state":…,"steps":[…],"steps_source":"record|audit","provider_processes":[…]}, or {"run_id","job_id","step","step_output"} with -s.
The State: line is `.run.state`. Table step numbers are one-based; JSON `step_index` is zero-based and durations are milliseconds.
Field reference: docs/runbooks/stuck-job-runs.md (Read `orbit run show` output).

Examples:
  orbit run show
  orbit run show jrun-20260426-0631
  orbit run show jrun-20260426-0631 -s implement_one --json
