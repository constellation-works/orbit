Run a plugin's conformance goldens against this Orbit

Usage: orbit plugin test [OPTIONS] <DIR>

Arguments:
  <DIR>
          Plugin source: a directory holding `.orbit-plugin/plugin.yaml`, or that `.orbit-plugin` directory itself

Options:
      --first-party
          Treat the source as a verified first-party checkout, so an `origin: orbit` manifest runs as it would after a verified install

      --grant <GRANTS>
          Consent to these grants for this run (repeatable, comma-separated): fs, network, env_pass, orbit_tools, unsandboxed. Same names as `orbit plugin enable --grant`. Required when the manifest asks for an unconfined backend, a write root that resolves outside the run's temp directory, `network: any`, or `env_pass`, unless `--accept-requested` is set. Does not record a host grant

      --accept-requested
          Run under the profile the manifest requests, including an unconfined backend, write roots outside the run's temp directory, `network: any`, and `env_pass`. Does not record a host grant

      --case <NAME>
          Run exactly one named conformance case

      --update-goldens
          Replace mismatched `expect.output` values with the actual output

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
