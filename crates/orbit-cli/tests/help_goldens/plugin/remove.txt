Uninstall a plugin from this machine

Usage: orbit plugin remove [OPTIONS] <NAME>

Arguments:
  <NAME>
          Plugin namespace

Options:
      --yes
          Confirm permanent removal of the plugin install

      --record-only
          Remove only this host's record of the plugin, leaving every installed file in place. Clears a record whose install path this host refuses, without deleting the path it names

      --purge-state
          Also delete this plugin's Orbit-owned state directory

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
