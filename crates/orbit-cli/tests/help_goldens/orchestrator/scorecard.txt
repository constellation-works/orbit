Usage: orbit orchestrator scorecard [OPTIONS]

Options:
      --window <WINDOW>
          Count work in this period ending now
          
          [default: 30d]
          [possible values: 1h, 24h, 7d, 30d, 90d, all]

      --min-support <MIN_SUPPORT>
          Units of work a row needs before it is ranked
          
          [default: 10]

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
