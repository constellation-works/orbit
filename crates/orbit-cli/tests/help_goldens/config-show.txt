Display configuration values, with source provenance

Usage: orbit config show [OPTIONS]

Options:
      --scope <SCOPE>
          Select the layered effective config or resolve one file in isolation, including built-in defaults for keys that file omits
          
          [default: effective]
          [possible values: effective, global, workspace]

      --all
          List every key, including unconfigured advanced keys and sections whose keys are all unset, plus the Paths, Crew purposes and Review summaries
          
          [aliases: --advanced]

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
