Preview or apply the audited reset of a delivery consumer: forget its coverage debt and re-baseline at the branch head

Usage: orbit auto-task reset [OPTIONS] <NAME>

Arguments:
  <NAME>
          Definition name

Options:
      --reason <REASON>
          Operator explanation, retained in the audit record. Required to apply; without it the command previews and writes nothing

      --force
          Reset even while an action is executing. The admitted task or run is abandoned, not cancelled

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
