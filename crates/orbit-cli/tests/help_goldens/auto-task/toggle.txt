Enable or disable a definition (the kill-switch; not a delete)

Usage: orbit auto-task toggle [OPTIONS] <NAME> <STATE>

Arguments:
  <NAME>
          Definition name

  <STATE>
          Whether to enable (`on`) or disable (`off`)

          Possible values:
          - on:  Enable the definition
          - off: Disable the definition (preserved, not deleted)

Options:
      --dry-run
          With `on` for a condition definition: show what enabling would baseline or fire, and whether max_matches refuses it, without enabling anything

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
