Mint a task from a definition now (ignores schedule, dedupe, and `enabled`; leaves the scheduler cursor untouched)

Usage: orbit auto-task mint [OPTIONS] <NAME>

Arguments:
  <NAME>
          Definition name

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
