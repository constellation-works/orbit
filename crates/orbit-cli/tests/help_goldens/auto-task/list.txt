List every auto-task definition in this workspace

Usage: orbit auto-task list [OPTIONS]

Options:
      --enabled
          Show only enabled (or, with `--disabled`, only disabled) definitions

      --root <ROOT>
          Orbit data directory to use (overrides every other source)

      --disabled
          Show only disabled definitions

      --workspace <SELECTOR>
          Active workspace to use: registered name, `ws_*` ID or checkout path

      --include-inactive-plugins
          Also list definitions seeded by a plugin that is switched off in this workspace or on the host, marked inactive with the reason
          
          [aliases: --all]

      --format <MODE>
          Output format (default: auto — a table on a terminal, plain text when piped)

          Possible values:
          - auto:   Decide from the sink: a table on a terminal, plain text otherwise
          - table:  Aligned columns with a header
          - plain:  Untruncated text with tab-separated fields; a header row only with --header
          - json:   A single JSON document
          - ndjson: One complete JSON document per line

      --json
          Output as JSON (shorthand for --format json; always pretty-printed)

      --header
          Start plain output with a tab-separated header row (table output always has one)

  -h, --help
          Print help (see a summary with '-h')
