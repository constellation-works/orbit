Show a single definition by name

Usage: orbit auto-task show [OPTIONS] <NAME>

Arguments:
  <NAME>
          Definition name

Options:
      --preview
          Preview the baseline and source observations without admitting actions

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
