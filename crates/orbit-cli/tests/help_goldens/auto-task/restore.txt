Reinstate a deleted shipped default with its shipped content

Usage: orbit auto-task restore [OPTIONS] <NAME>

Arguments:
  <NAME>
          Shipped default name

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
