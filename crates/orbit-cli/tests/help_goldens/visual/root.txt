Capture the working tree beside a task's mocks, or accept a disputed visual finding

Usage: orbit visual [OPTIONS] <COMMAND>

Commands:
  capture         Capture the working tree beside each of a task's mocks
  accept-dispute  Accept a disputed blocking visual finding so the delivery can land

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
