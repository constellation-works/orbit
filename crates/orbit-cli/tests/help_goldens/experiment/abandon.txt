Abandon an experiment without a conclusion

Usage: orbit experiment abandon [OPTIONS] --reason <REASON> <ID>

Arguments:
  <ID>
          The experiment's id or name

Options:
      --reason <REASON>
          Why, recorded on the event

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
