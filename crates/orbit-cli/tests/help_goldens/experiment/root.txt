Define, run and conclude experiments over agent treatments

Usage: orbit experiment [OPTIONS] <COMMAND>

Commands:
  create    Define a new draft experiment
  update    Edit a draft experiment's definition
  clone     Copy an experiment's definition into a new draft
  start     Start a draft experiment
  pause     Pause a running experiment
  resume    Resume a paused experiment
  reweight  Change arm weights or retire arms, opening a new segment
  assign    Force a task into a shadow experiment arm
  conclude  Conclude an experiment with the chosen arm, or none
  abandon   Abandon an experiment without a conclusion
  show      Show one experiment with its arms and event log
  list      List the workspace's experiments
  readout   Show an experiment's per-arm outcomes, intervals and verdict

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
