Grant one script at its current manifest and entry digests

Usage: orbit script grant [OPTIONS] <NAME>

Arguments:
  <NAME>
          Script name

Options:
      --network <NETWORK>
          Network the grant allows (default: what the manifest requests)

      --read-root <READ_ROOTS>
          Extra absolute read root to grant (repeatable)

      --write-root <WRITE_ROOTS>
          Extra absolute write root to grant (repeatable)

      --env-pass <ENV_PASS>
          Extra environment variable name to pass (repeatable)

      --follower
          Grant for a pull follower host instead of the workspace owner

      --output-max-files <COUNT>
          Most output files one step may keep, up to 64 (default 8). Each grant states it again; a re-grant without it returns to the default

      --output-max-file-bytes <BYTES>
          Largest output file one step may keep, in bytes, up to 67108864 (64 MiB; default 1048576). A step's whole output set is also bounded by files times bytes and never exceeds 256 MiB

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
