Delete applied task commit journal rows older than 14 days, keeping each task's newest

Usage: orbit gc journal [OPTIONS]

Options:
      --confirm
          Delete what the plan lists; without this flag the command only reports
          
          [aliases: --apply]

      --older-than-days <DAYS>
          Retention window in days (default 14)

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header

Without --confirm this only reports. Only applied rows of this workspace, and of workspace ids that are no longer registered, are selected; another registered workspace keeps its own window. An applied row is a commit decision already published to its task, so recovery never reads it again. Prepared and committed rows, which recovery replays, aborted rows, and each task's newest applied row are never deleted. The rows are selected by one read that holds no write lock, then deleted by key in batches of 1,000 rows, each its own write transaction. Freed pages stay in the store file; VACUUM it while Orbit is idle to return them to the filesystem.

Examples:
  orbit gc journal
  orbit gc journal --confirm --json
