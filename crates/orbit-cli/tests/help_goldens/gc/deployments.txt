Remove deployment directories, executable backups and store backups in the Orbit home beyond the newest of each, always keeping the rollback executable

Usage: orbit gc deployments [OPTIONS]

Options:
      --confirm
          Remove what the report lists; without this flag the command only reports
          
          [aliases: --yes]

      --dry-run
          Explicitly request the default non-destructive mode

      --keep <N>
          Newest entries to keep in each class, besides the rollback-pinned ones
          
          [default: 2]

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header

Without --confirm this only reports. Three classes are counted separately, and each keeps its newest entries. The installed executable and every <executable>.previous rollback copy are never removed, nor is a deployment whose manifest names those bytes; those do not count toward --keep. Links are removed, never followed.

The three classes, the name markers and how newest is chosen: installed orbit-setup skill `references/maintenance-local-deploys.md`.

Examples:
  orbit gc deployments
  orbit gc deployments --keep 1 --confirm --json
