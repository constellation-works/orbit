Prune audit rows older than `retention.audit_days` and the audit blobs no remaining row names

Usage: orbit gc audit [OPTIONS]

Options:
      --apply
          Delete what the plan lists; without this flag the command only reports

      --older-than-days <DAYS>
          Retention window in days, overriding `retention.audit_days` (default 60)

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header

Without --apply this only reports. The command audit (`audit_events`) is host-wide. Run audit rows are this workspace's, plus rows whose workspace id is no longer registered; another registered workspace keeps its own window. Blobs are this workspace's. A blob is kept while any remaining run audit row, run step or pipeline state names it, while a pending-publication marker newer than the cutoff names it, and for 24 hours after it was last written. Deletes run in batches of 1,000 rows, each its own write transaction. Freed pages stay in the store file; VACUUM it while Orbit is idle to return them to the filesystem.

Examples:
  orbit gc audit
  orbit gc audit --older-than-days 30 --apply --json
