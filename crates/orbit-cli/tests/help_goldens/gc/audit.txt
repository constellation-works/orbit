Prune audit rows older than `retention.audit_days` and the audit blobs no remaining row names

Usage: orbit gc audit [OPTIONS]

Options:
      --confirm
          Delete what the plan lists; without this flag the command only reports
          
          [aliases: --apply]

      --older-than-days <DAYS>
          Retention window in days, overriding `retention.audit_days` (default 60)

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header

Without --confirm this only reports. The command audit (`audit_events`) is host-wide. Run audit rows are this workspace's, plus rows whose workspace id is no longer registered; another registered workspace keeps its own window. Blobs are this workspace's. A blob is kept while any remaining run audit row, run step or pipeline state names it.

How long a fresh blob is kept, and how deletes run: installed orbit-setup skill `references/maintenance-storage.md`.

Examples:
  orbit gc audit
  orbit gc audit --older-than-days 30 --confirm --json
