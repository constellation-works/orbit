Drop the pipeline state of terminal runs older than `retention.runs_days`, keeping their run and step rows

Usage: orbit gc runs [OPTIONS]

Options:
      --confirm
          Drop what the plan lists; without this flag the command only reports
          
          [aliases: --apply]

      --older-than-days <DAYS>
          Retention window in days, overriding `retention.runs_days` (default 60, minimum 30)

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header

Without --confirm this only reports. Only success, failed, timeout, cancelled and interrupted runs of this workspace, and of workspace ids that are no longer registered, are selected; another registered workspace keeps its own window. A held run, which review evidence can still resume, and every non-terminal run are never touched. The run row, its steps and its summary stay, so `orbit run show` and run history keep working, and `archived_at` records when the state was dropped.

Rows kept by count, and the resource-history window: installed orbit-setup skill `references/maintenance-storage.md`.

Examples:
  orbit gc runs
  orbit gc runs --confirm
