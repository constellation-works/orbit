Drop the pipeline state of terminal runs older than `retention.runs_days`, keeping their run and step rows

Usage: orbit gc runs [OPTIONS]

Options:
      --apply
          Drop what the plan lists; without this flag the command only reports

      --root <ROOT>
          Override the Orbit root directory (highest precedence)

      --older-than-days <DAYS>
          Retention window in days, overriding `retention.runs_days` (default 60)

      --workspace <SELECTOR>
          Select a workspace by registered name, logical ID (`ws_*`), or absolute checkout path. Distinct from `--root`, which overrides the Orbit data directory. Only active workspaces may be bound; commands fail if the workspace status is not active

      --format <MODE>
          Output format (default: auto — a table on a terminal, plain text when piped)

          Possible values:
          - auto:   Decide from the sink: a table on a terminal, plain text otherwise
          - table:  Aligned columns with a header
          - plain:  Untruncated text with tab-separated fields; a header row only with --header
          - json:   A single JSON document
          - ndjson: One complete JSON document per line

      --json
          Output as JSON (shorthand for --format json; always pretty-printed)

      --header
          Start plain output with a tab-separated header row (table output always has one)

  -h, --help
          Print help (see a summary with '-h')

Without --apply this only reports. Only success, failed, timeout, cancelled and interrupted runs of this workspace, and of workspace ids that are no longer registered, are selected; another registered workspace keeps its own window. A held run, which review evidence can still resume, and every non-terminal run are never touched. The run row, its steps and its summary stay, so `orbit run show` and run history keep working, and `archived_at` records when the state was dropped. The host's per-minute run and host resource history, and the admission forecasts recorded against it, older than 30 days go in the same pass, whatever the window.

Examples:
  orbit gc runs
  orbit gc runs --apply
