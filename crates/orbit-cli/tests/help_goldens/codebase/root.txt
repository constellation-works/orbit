Rank the repository paths that are risky for agents to change

Usage: orbit codebase [OPTIONS] <COMMAND>

Commands:
  analytics  Show the codebase rankings and the paths several share
  show       Show one path's rankings and the tasks behind each count
  related    List files that usually change alongside a repository file

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
