Show the codebase rankings and the paths several share

Usage: orbit codebase analytics [OPTIONS]

Options:
      --window <WINDOW>
          Counted period ending now
          
          [default: 90d]
          [possible values: 7d, 30d, 90d, all]

      --min-support <MIN_SUPPORT>
          Smallest denominator a ranked row needs
          
          [default: 15]

      --rollup <ROLLUP>
          Group paths by file, parent directory or crate
          
          [default: file]
          [possible values: file, dir, crate]

      --nature <NATURE>
          Count only regressions of this nature (absent: no classification)
          
          [possible values: broke_existing, defect_in_new, incomplete, merge_reintroduced, contract_drift, unclassified, absent]

      --escape <ESCAPE>
          Count only regressions that escaped this way (absent: no classification)
          
          [possible values: no_test, test_not_selected, platform_only, review_missed, spec_ambiguous, nondeterministic, unclassified, absent]

      --layer <LAYER>
          Count only regressions whose fix sits in this layer
          
          [possible values: ci_tests, docs_skills, dashboard, sandbox_policy, store_migration, vcs_delivery, config, cli_mcp, runtime_lifecycle, other, unknown]

      --detected-by <DETECTED_BY>
          Count only regressions found this way
          
          [possible values: delivery_review, security_review, code_review, qa_sweep, post_merge_ci, production_run, operator, other]

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header

"Touched" means a task's declared footprint, not the landed diff.
Follow a ranked path to its tasks with `orbit codebase show <path>`.
