List files that usually change alongside a repository file

Usage: orbit codebase related [OPTIONS] <PATH>

Arguments:
  <PATH>
          A repository-relative file path

Options:
      --window <WINDOW>
          Landed period ending now
          
          [default: 30d]
          [possible values: 7d, 30d, 90d, all]

      --min-support <MIN_SUPPORT>
          Minimum shared landed tasks
          
          [default: 15]

      --top <TOP>
          Maximum related paths (1–100)
          
          [default: 10]

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
