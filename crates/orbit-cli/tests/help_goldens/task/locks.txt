Inspect, reserve, and release task file locks

Usage: orbit task locks [OPTIONS] <COMMAND>

Commands:
  list        Show files locked by active (in-progress/review) tasks and reservations
  contention  Show which files the pending backlog collides on (what caps parallelism)
  reserve     Claim a file surface for a bounded window before starting work on it
  release     Release a stale task lock reservation (operator/admin escape hatch)

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
