Read one stored artifact back out of a task

Usage: orbit task artifact get [OPTIONS] <ID> <PATH>

Arguments:
  <ID>
          Task ID that owns the artifact

  <PATH>
          Artifact path relative to the task artifacts directory, as listed by `orbit task show <ID> --fields artifacts`

Options:
      --host <HOST>
          Host that `--workspace` names (`orbit host list` name or `machine_id`); without it a task id routes by its prefix

      --out <OUT>
          Write the artifact's bytes to this file instead of printing them

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
