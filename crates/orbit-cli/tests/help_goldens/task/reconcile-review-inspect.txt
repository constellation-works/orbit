Show whether the task's merged delivery can be reconciled, and why not

Usage: orbit task reconcile-review inspect [OPTIONS] <ID>

Arguments:
  <ID>
          Task in review whose foreign delivery merged

Options:
      --host <HOST>
          Host that `--workspace` names (`orbit host list` name or `machine_id`); without it a task id routes by its prefix

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
