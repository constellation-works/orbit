Show which files the pending backlog collides on (what caps parallelism)

Usage: orbit task locks contention [OPTIONS]

Options:
      --limit <LIMIT>
          Maximum hotspot rows to show. Default 10
          
          [default: 10]

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header

Examples:
  orbit task locks contention
  orbit task locks contention --limit 25
  orbit task locks contention --json

TASKS counts pending tasks whose lock surface overlaps that selector; a
selector claimed by one task constrains nothing and is not listed.

GROUPS counts clusters of pending tasks linked by overlapping surfaces.
Tasks in different groups can never block each other, so the group count
is a floor on how many dispatch can admit at once — not a ceiling, since
two tasks inside one group are often compatible and merely linked through
a third.

Surfaces are the ones conflict admission reserves: declared selectors,
pruned of paths that no longer exist. A task declaring nothing locks
nothing and is counted apart.
