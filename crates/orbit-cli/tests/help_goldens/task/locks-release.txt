Release a stale task lock reservation (operator/admin escape hatch)

Usage: orbit task locks release [OPTIONS] <RESERVATION_ID>

Arguments:
  <RESERVATION_ID>
          Reservation ID to release (see `orbit task locks list --json`)

Options:
      --confirm
          Confirm release of the reservation

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
