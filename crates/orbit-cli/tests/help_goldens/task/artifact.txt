Manage task artifact files

Usage: orbit task artifact [OPTIONS] <COMMAND>

Commands:
  put  Store a source file under a task's artifacts directory
  get  Read one stored artifact back out of a task

Options:
      --host <HOST>
          Host that `--workspace` names (`orbit host list` name or `machine_id`); without it a task id routes by its prefix

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
