Record an audited disposition of a failure the base already had

Usage: orbit task reconcile-review accept-baseline [OPTIONS] --reconciliation <RECONCILIATION> --command <COMMAND> --remediation <REMEDIATION> --reason <REASON> <ID>

Arguments:
  <ID>
          Task the reconciliation belongs to

Options:
      --host <HOST>
          Host that `--workspace` names (`orbit host list` name or `machine_id`); without it a task id routes by its prefix

      --reconciliation <RECONCILIATION>
          Reconciliation waiting for a baseline disposition

      --command <COMMAND>
          Required command whose failure reproduced at the base

      --remediation <REMEDIATION>
          Commit on the landing branch, landed on top of the delivery's merge or squash commit, that remediates the failure

      --reason <REASON>
          Why the baseline failure is accepted; recorded with the disposition

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
