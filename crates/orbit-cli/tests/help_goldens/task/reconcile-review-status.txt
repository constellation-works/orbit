Show reconciliation outcomes, their runs and the next step

Usage: orbit task reconcile-review status [OPTIONS] <ID>

Arguments:
  <ID>
          Task whose reconciliations to show

Options:
      --host <HOST>
          Host that `--workspace` names, by registered host name or `machine_id` (see `orbit host list`). Orbit reads that host's live workspace list and uses the selector it lists for the workspace. Without it, a task id goes to the host its prefix names

      --reconciliation <RECONCILIATION>
          Show only this reconciliation

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
