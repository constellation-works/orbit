Requeue a blocked task onto its published candidate

Usage: orbit task requeue [OPTIONS] --reason <REASON> <ID>

Arguments:
  <ID>
          Blocked task to requeue

Options:
      --host <HOST>
          Host that `--workspace` names, by registered host name or `machine_id` (see `orbit host list`). Orbit reads that host's live workspace list and uses the selector it lists for the workspace. Without it, a task id goes to the host its prefix names

      --reason <REASON>
          Explanation recorded with the operator decision

      --discard-candidate
          Discard the published or kept candidate and rerun from scratch

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
