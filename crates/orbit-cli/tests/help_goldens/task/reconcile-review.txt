Validate and independently review the already-merged head of a recovered follower delivery so its task can complete from review

Usage: orbit task reconcile-review [OPTIONS] <COMMAND>

Commands:
  inspect          Show whether the task's merged delivery can be reconciled, and why not
  submit           Admit a reconciliation run; resubmitting the same key replays it
  status           Show reconciliation outcomes, their runs and the next step
  accept-baseline  Record an audited disposition of a failure the base already had

Options:
      --host <HOST>
          Host that `--workspace` names, by registered host name or `machine_id` (see `orbit host list`). Orbit reads that host's live workspace list and uses the selector it lists for the workspace. Without it, a task id goes to the host its prefix names

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
