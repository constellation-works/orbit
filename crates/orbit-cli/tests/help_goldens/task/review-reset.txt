Reset a review lineage budget with an audited operator reason

Usage: orbit task review-reset [OPTIONS] --lineage <LINEAGE> --reason <REASON> <ID>

Arguments:
  <ID>
          Task belonging to the selected lineage

Options:
      --host <HOST>
          Host that `--workspace` names (`orbit host list` name or `machine_id`); without it a task id routes by its prefix

      --lineage <LINEAGE>
          Exact lineage key from the refusal or review manifest

      --reason <REASON>
          Explanation recorded with the operator decision

      --adopt-configured-budget
          Adopt the current configured budget instead of the captured budget

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
