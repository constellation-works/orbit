Show one row's terms and the tasks behind each count

Usage: orbit agents show [OPTIONS] --role <ROLE> --crew <CREW>

Options:
      --role <ROLE>
          The agent role to score
          
          [possible values: orchestrators, implementers, reviewers, pilots]

      --crew <CREW>
          The row's crew, or the orchestrator name tasks record

      --model <MODEL>
          The row's model; optional when the crew has one row

      --window <WINDOW>
          Count work in this period, or over the newest delivery attempts
          
          [default: 30d]
          [possible values: 1h, 24h, 7d, 30d, 90d, all, last50, last200, last500]

      --min-support <MIN_SUPPORT>
          Units of work a row needs before it is ranked
          
          [default: 10]

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
