Score agents by model and recorded effort

Usage: orbit agents [OPTIONS] <COMMAND>

Commands:
  scorecard      Show one role's scorecard rows by model and recorded effort
  show           Show one row's terms and the tasks behind each count
  ci-failures    List required-check failures on candidate heads by cause
  rank-snapshot  Read a frozen model-ranking snapshot, or freeze a new one
  rank           Rank implementer models by quality and reliability, in tie bands
  vision-probe   Check that each crew's model sees images: run the canary per crew

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
