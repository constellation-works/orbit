Score agents by crew and model, and show the crew ladder

Usage: orbit agents [OPTIONS] <COMMAND>

Commands:
  scorecard     Show one role's scorecard rows by crew and model
  show          Show one row's terms and the tasks behind each count
  ladder        Show each tier's pool, floor, candidate rung and shadow trial
  vision-probe  Check that each crew's model sees images: run the canary per crew

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
