Coordinate path leases with the workspace owner

Usage: orbit lease [OPTIONS] <COMMAND>

Commands:
  request  Request an advisory or hard path lease
  renew    Renew an active lease from now
  release  Release a path lease early
  show     Inspect a lease in any state
  list     List active advisory and hard leases
  check    Check path coverage and overlapping holders

Options:
  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
