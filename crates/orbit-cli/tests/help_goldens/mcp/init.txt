Initialize MCP client integration for the current workspace

New entries register agent-only authority, as bare `orbit mcp serve` does. Existing operator entries retain their launch and workspace binding; remove the entry first to replace it with agent authority. `--federated` instead adds a separate client entry for the session-unbound mux and preserves the default v1 entry. For the operator-authorized bootstrap integration (workflow dispatch, `orbit.command.exec`), use `orbit workspace init --mcp` instead.

Usage: orbit mcp init [OPTIONS]

Options:
      --auto
          Use auto-detected provider targets for the current workspace

      --client <CLIENT>
          Target a supported MCP client integration. Can be repeated
          
          [possible values: claude, codex, gemini, antigravity, grok, cursor, vscode, windsurf]

      --claude
          Target Claude Code integration only

      --codex
          Target Codex CLI integration only

      --gemini
          Target Gemini CLI integration only

      --antigravity
          Target Antigravity CLI integration only

      --grok
          Target Grok Build integration only

      --cursor
          Target Cursor integration only

      --vscode
          Target VS Code integration only

      --windsurf
          Target Windsurf integration only

      --all
          Target all supported MCP client integrations

      --scope <SCOPE>
          Scope for written config files (workspace: repo-local, home: user-level)

          Possible values:
          - home:      Write to user-level MCP config (including shared ~/.claude.json for Grok)
          - workspace: Write to repo-local MCP config (including shared .mcp.json for Grok). Default
          
          [default: workspace]

      --federated
          Register the federated mux as a separate `orbit-federated` MCP server.
          
          The generated entry launches `orbit mcp serve --mode federated` and does not replace the existing v1 `orbit` server entry.

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
