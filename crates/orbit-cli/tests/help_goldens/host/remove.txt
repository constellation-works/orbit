Remove a registered host

Usage: orbit host remove [OPTIONS] <HOST>

Arguments:
  <HOST>
          Host name (case-insensitive) or machine_id

Options:
      --force
          Remove the entry even while a replica checkout or pull drain routes to it

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
