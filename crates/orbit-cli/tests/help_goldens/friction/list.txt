List friction records

Usage: orbit friction list [OPTIONS]

Options:
      --model <MODEL>
          Optional model filter

      --status <STATUS>
          Status filter: open, triaged or resolved, comma-separated for several, or `all` for every status
          
          [default: open,triaged]

      --tag <TAG>
          Optional tag filter

      --month <MONTH>
          Optional YYYY-MM month filter for reported records

      --q <Q>
          Optional case-insensitive query over id, model, tags, status, task, and body

      --from <FROM>
          Optional RFC3339 lower bound for created_at

      --to <TO>
          Optional RFC3339 upper bound for created_at

      --limit <LIMIT>
          Optional maximum number of records to return

      --offset <OFFSET>
          Optional number of records to skip

      --order <ORDER>
          Creation-time order: `oldest` or `newest` first
          
          [default: newest]

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
