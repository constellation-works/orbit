List friction records

Usage: orbit friction list [OPTIONS]

Options:
      --model <MODEL>
          Optional model filter

      --root <ROOT>
          Orbit data directory to use (overrides every other source)

      --status <STATUS>
          Status filter: open, triaged or resolved, comma-separated for several, or `all` for every status
          
          [default: open,triaged]

      --workspace <SELECTOR>
          Active workspace to use: registered name, `ws_*` ID or checkout path

      --tag <TAG>
          Optional tag filter

      --month <MONTH>
          Optional YYYY-MM month filter for reported records

      --q <Q>
          Optional case-insensitive query over id, model, tags, status, task, and body

      --from <FROM>
          Optional RFC3339 lower bound for created_at

      --to <TO>
          Optional RFC3339 upper bound for created_at

      --limit <LIMIT>
          Optional maximum number of records to return

      --offset <OFFSET>
          Optional number of records to skip

      --order <ORDER>
          Creation-time order: `oldest` or `newest` first
          
          [default: newest]

      --format <MODE>
          Output format (default: auto — a table on a terminal, plain text when piped)

          Possible values:
          - auto:   Decide from the sink: a table on a terminal, plain text otherwise
          - table:  Aligned columns with a header
          - plain:  Untruncated text with tab-separated fields; a header row only with --header
          - json:   A single JSON document
          - ndjson: One complete JSON document per line

      --json
          Output as JSON (shorthand for --format json; always pretty-printed)

      --header
          Start plain output with a tab-separated header row (table output always has one)

  -h, --help
          Print help (see a summary with '-h')
