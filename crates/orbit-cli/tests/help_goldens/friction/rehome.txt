Move a friction record into the registered workspace that owns it

Usage: orbit friction rehome [OPTIONS] --to-workspace <TO_WORKSPACE> <ID>

Arguments:
  <ID>
          Friction record ID, e.g. FYYYY-MM-NNN

Options:
      --to-workspace <TO_WORKSPACE>
          Registered name or ID of the workspace that owns this friction

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
