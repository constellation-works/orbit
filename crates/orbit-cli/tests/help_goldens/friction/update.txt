Update triage metadata for a friction record

Usage: orbit friction update [OPTIONS] <ID>

Arguments:
  <ID>
          Friction record ID, e.g. FYYYY-MM-NNN

Options:
      --root <ROOT>
          Orbit data directory to use (overrides every other source)

      --status <STATUS>
          Optional status: open, triaged, or resolved

      --tag <TAGS>
          Optional replacement taxonomy tag; repeat or comma-separate for multiple tags

      --workspace <SELECTOR>
          Active workspace to use: registered name, `ws_*` ID or checkout path

      --body <BODY>
          Optional replacement markdown body

      --rehome-to <REHOME_TO>
          Optional registered workspace that owns a friction recorded in the wrong one; moves the record there unless `move` is false. An empty string clears a recorded disposition

      --move <MOVE>
          With `rehome_to`: false records the `rehome_required` disposition without moving, for a workspace that is not registered here; defaults to true
          
          [possible values: true, false]

      --title <TITLE>
          Optional replacement title, max 120 chars; empty restores derivation

      --format <MODE>
          Output format (default: auto — a table on a terminal, plain text when piped)

          Possible values:
          - auto:   Decide from the sink: a table on a terminal, plain text otherwise
          - table:  Aligned columns with a header
          - plain:  Untruncated text with tab-separated fields; a header row only with --header
          - json:   A single JSON document
          - ndjson: One complete JSON document per line

      --json
          Output as JSON (shorthand for --format json; always pretty-printed)

      --header
          Start plain output with a tab-separated header row (table output always has one)

  -h, --help
          Print help (see a summary with '-h')
