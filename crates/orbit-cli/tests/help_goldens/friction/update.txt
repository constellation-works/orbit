Update triage metadata for a friction record

Usage: orbit friction update [OPTIONS] <ID>

Arguments:
  <ID>
          Friction record ID, e.g. FYYYY-MM-NNN

Options:
      --status <STATUS>
          Optional status: open, triaged, or resolved

      --tag <TAGS>
          Optional replacement taxonomy tag; repeat or comma-separate for multiple tags

      --body <BODY>
          Optional replacement markdown body

      --rehome-to <REHOME_TO>
          Optional registered workspace that owns a friction recorded in the wrong one; moves the record there unless --move false. An empty string clears a recorded disposition

      --move <MOVE>
          With --rehome-to: false records the rehome-required disposition without moving, for a workspace that is not registered here; defaults to true
          
          [possible values: true, false]

      --title <TITLE>
          Optional replacement title, max 120 chars; empty restores derivation

  -h, --help
          Print help (see a summary with '-h')

Global options (see 'orbit --help' for descriptions):
  --root <ROOT>
  --workspace <SELECTOR>
  --format <MODE>
  --json
  --header
