Upgrade an installed plugin and review requested-permission changes

Usage: orbit plugin upgrade [OPTIONS] <NAME> [SOURCE]

Arguments:
  <NAME>    Installed plugin namespace
  [SOURCE]  Replacement source; defaults to the source recorded at install time

Options:
      --grant <GRANTS>        Complete permission grant set authorizing and enabling the new manifest (repeatable, comma-separated): fs, network, env_pass, orbit_tools, unsandboxed. Without it, widened requests disable the plugin and clear its grants
      --root <ROOT>           Override the Orbit root directory (highest precedence)
      --workspace <SELECTOR>  Select a workspace by registered name, logical ID (`ws_*`), or absolute checkout path. Distinct from `--root`, which overrides the Orbit data directory. Only active workspaces may be bound; commands fail if the workspace status is not active
  -h, --help                  Print help
